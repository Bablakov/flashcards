# Konkurentnyj analiz i idei razvitija — flashcards-editor

**Data:** 2026-05-11
**Avtor analiza:** Senior Product Research
**Kontekst:** Next.js + React + Capacitor (Android), lightning-fs, Git sync, Leitner 1-5, TTS

---

## 1. Краткий gap-анализ конкурентов

### 1.1 Anki / AnkiDroid (open source, золотой стандарт SRS)

**Что у них есть, чего нет у меня:**
- **FSRS-6** — машинно-обученный алгоритм планирования, обученный на 700M+ повторений; экономит 20-30% повторений vs SM-2 и Leitner. С июля 2025 — дефолт во всех клиентах Anki (25.07) и AnkiDroid (2.22+).
- **Image occlusion** (скрытие частей изображения) — критично для анатомии, диаграмм, карт. Уже базовая фича в Anki, AnkiHub, Voovo, Mochi.
- **Огромная экосистема shared decks** через AnkiWeb, AnkiHub, AnkiCollab — миллионы готовых колод, краудсорсинг и обновления.
- **Add-ons / custom card templates** — кастомные HTML/CSS/JS поля, продвинутые типы карт.

### 1.2 Quizlet (массовый рынок, gamification + AI)

**Что у них есть, чего нет у меня:**
- **Magic Notes** — загрузка конспекта/PDF → автогенерация флешкарт, тестов, конспектов, эссе-тем (база ожиданий в 2026).
- **Memory Score + автоматические планы повторения** — измеряет уровень знания и сам составляет график.
- **Множество режимов изучения**: Learn, Test, Match (мини-игра), Write, Spell, Blast (аркада), Brain Beats (флешкарта → песня для запоминания).
- **Quick Summary** — резюмирует плотные тексты в ключевые концепции.

### 1.3 Memrise (мнемоника, видео носителей, AI-разговоры)

**Что у них есть, чего нет у меня:**
- **MemBot + AI Buddies** (Grammar/Role Play/Translator/Culture) — диалоговая практика голосом и текстом на GPT-3.5/4.
- **Видео native speakers** в контексте — короткие ролики с реальными носителями языка.
- **Exam Prep + Podchats** (фев 2026) — подготовка к IELTS/GCSE/A-Level с AI-оцениванием speaking.
- Глубокая ориентация на язык как сильный нишевый продукт.

### 1.4 Brainscape (Confidence-Based Repetition)

**Что у них есть, чего нет у меня:**
- **CBR-шкала 1-5** — не bad/neutral/good, а пять уровней уверенности; алгоритм точнее моделирует кривую забывания.
- **Bookmark** — отдельная пометка карты «вернуться позже / обсудить с тьютором», в дополнение к рейтингу.
- **Stale detection** — карты, не виденные давно, поднимаются по приоритету независимо от рейтинга.
- Персонализированный темп под расписание (45 мин/день vs 3 мин раз в пару дней).

### 1.5 Mochi.cards (markdown, минимализм)

**Что у них есть, чего нет у меня:**
- **Markdown + LaTeX** для контента карты, code blocks с подсветкой синтаксиса.
- **Cloze deletion** через `{{...}}` синтаксис — must-have для языков, кода, медицины.
- **Bi-directional links** между картами через `[[карта]]`, backlinks автоматом.
- **Diagram cards / image occlusion** + специальные инструменты для иероглифов (рисование).
- Очень быстрые keyboard-shortcuts для создания карт.

### 1.6 RemNote (студенты, концепт-графы)

**Что у них есть, чего нет у меня:**
- **Knowledge graph** — визуализация связей между концептами и заметками.
- **Exam date scheduling** — указываешь дату экзамена и intensity (casual/regular/intense), алгоритм автоматически уплотняет график.
- **Hierarchical notes → flashcards** — иерархия заметок превращается в карты без дублирования.
- **AI flashcard generation** из PDF/конспектов/транскриптов лекций.

### 1.7 Tinycards (Duolingo, закрыт 1 сент 2020)

**Почему закрылся** — Duolingo решил сконцентрировать ресурсы на основном приложении; отдельный flashcard-продукт не оправдывал команду. **Уроки для нас:**
- Самостоятельный flashcard-продукт без сильной дифференциации тяжело удерживать на массовом рынке.
- Нужна либо узкая ниша, либо open-source/инди-позиционирование (как Anki), либо AI-моат, либо встроенность в более крупный воркфлоу (как RemNote в заметки).
- Сам факт: даже у Duolingo с deep pocket не получилось — массовый рынок забирают Quizlet + Anki, ниши — все остальные.

## 3. Приоритизированный список идей (28 шт.)

### Critical — базовые ожидания, без которых пользователи уйдут

#### C1. FSRS-6 как опциональный алгоритм рядом с Leitner
Заменить/дополнить простой Leitner 1-5 на FSRS-6 (free spaced repetition scheduler). Можно держать оба: Leitner для новичков, FSRS для продвинутых. Это must-have в 2026 — даже не-Anki приложения переходят, потому что экономит 20-30% времени при том же retention.

#### C2. Cloze deletion (заполнение пропусков)
Синтаксис `{{c1::слово}}` внутри текста карты автоматически генерирует пропуски. Критично для языков, программирования, медицины, юриспруденции — самый эффективный тип карты для контекстной памяти.

#### C3. Image occlusion (скрытие зон на картинке)
Загружаешь диаграмму/карту/схему, выделяешь области прямоугольниками — каждая становится отдельной картой. Топ-1 запрос медиков, анатомов, геологов. Один из главных triggers для миграции с Quizlet на Anki.

#### C4. Markdown и LaTeX в тексте карты
Поддержать base markdown (bold/italic/code/lists/links) и LaTeX (`$E=mc^2$`). Сейчас текстовый формат явно проигрывает Mochi/RemNote/Anki для STEM-предметов и любых сложных заметок.

#### C5. Streaks, daily goal и heatmap календарь
Дневная цель (карт/день), счётчик подряд идущих дней, GitHub-like heatmap. Исследования показывают: 7+ day streak → 4.2x выше completion rate. Без этого retention в апп очень низкий.

#### C6. Режим «Type the answer» (ввод ответа с клавиатуры)
Дополнительно к flip + bad/neutral/good — режим, где нужно набрать ответ; апп проверяет с учётом опечаток (Levenshtein). Это «Learn/Write» режим Quizlet, активная отработка лучше пассивного переворота.

#### C7. Конфликт-резолюшн при Git pull
Сейчас, скорее всего, last-write-wins или ломается merge. Нужно: per-card timestamp, merge на уровне полей (текст/тег/box separately), UI для разрешения конфликтов вручную в редких случаях. CRDT-подобный merge для коллекции карт.

### High — большой uplift в удержании или обучении

#### H1. AI-генерация карт из PDF / текста / картинки
Загружаешь PDF лекции, конспект, скриншот — LLM генерирует карты Q/A или cloze. Это «новый base expectation» 2026 (Magic Notes, RemNote AI, StudyGlen, Laxu). Можно через Anthropic/OpenAI API ключ пользователя — не платим за инфру, privacy сохраняется.

#### H2. Несколько режимов изучения помимо flip
Match (соедини пары), Multiple choice (4 варианта из колоды), Listen (только аудио → пиши/выбирай), Reverse review (back → front). У Quizlet 5+ режимов, это меняет рутину и удержание.

#### H3. Confidence-based 1-5 шкала (опция)
В дополнение к bad/neutral/good — режим Brainscape с 5 уровнями уверенности. Алгоритм точнее, пользователи Brainscape считают это самым удобным UX для самооценки.

#### H4. Bookmark / favorite карт отдельно от рейтинга
«Звёздочка» — пометить карту как требующую внимания (сложная, спорная, обсудить с тьютором). Не влияет на SRS, но даёт отдельный фильтр и smart-deck «избранные».

#### H5. Tag-based фильтры и smart decks
Учить только карты с тегом `medical`, `verbs`, или комбинацию `verbs AND difficult`. Smart deck = сохранённый запрос, автоматически обновляется. Сейчас теги, видимо, есть, но без glubokoj фильтрации.

#### H6. Bulk operations в редакторе колоды
Множественный выбор → массовое: смена тега, перенос в Leitner box, удаление, экспорт подмножества. Без этого работа с колодой 200+ карт мучительна.

#### H7. Statistics dashboard
Карты выучены / в работе / новые, retention rate по дням/неделям, время в апп, прогноз нагрузки на ближайшие 7 дней (из FSRS). Не «красивости» — реальный feedback loop motivating.

#### H8. Speech-to-text для записи карты голосом
Capacitor → native speech recognition (Android уже умеет). На ходу диктуешь front+back, апп создаёт карту. Сокращает фрикцию создания в 3-5x.

#### H9. Pronunciation check для языковых колод
Когда учишь back-сторону на иностранном — апп слушает твой голос и сравнивает с TTS-эталоном через Web Speech API recognition. Базовый scoring (есть/нет, можно простой Levenshtein на распознанном тексте).

#### H10. Resume study session + offline queue
Если приложение закрыли посреди сессии — на старте «продолжить с карты 12/30». Накопленные оценки сохраняются локально и синкаются в Git, даже если сети не было неделю.

#### H11. Импорт из Anki .apkg
Огромный TAM пользователей с готовыми Anki-колодами. Парсить SQLite-формат можно в браузере (sql.js). Это снимает барьер «у меня уже 5000 карт в Anki» — самый частый возражение.

#### H12. Темплейты карт (custom card types)
Несколько шаблонов: basic (front/back), basic+reverse (генерирует две карты), cloze, image occlusion, typed answer. Один deck может содержать разные типы.

### Medium — приятно иметь, не критично

#### M1. Reorder карт drag-and-drop в редакторе колоды
Сейчас, видимо, фиксированный порядок. Manual reorder + сортировки (по дате создания / последнему рейтингу / алфавиту / box).

#### M2. Bi-directional links между картами `[[карта]]`
Как Mochi/Obsidian: упоминание другой карты → авто-ссылка + backlinks. Полезно для концептуально связанных предметов (история, биология, право).

#### M3. Export в Anki .apkg формат
Симметрично импорту. Пользователь не lock-in — может «уйти». Парадоксально это increases trust и retention.

#### M4. Multiple front/back languages per card
Например front EN, back ES + IT (триязычные карты). Полезно для polyglots. Сейчас, видимо, ровно 2 стороны.

#### M5. Custom TTS voices / speed per language
Сейчас Web Speech API даёт системные голоса. Дать выбор голоса, скорости (0.5-2x), pause между сторонами per-deck. Опционально — кэширование TTS в Git как mp3.

#### M6. Drawing / handwriting на карте (Capacitor canvas)
Особенно для CJK, математики, химии: написать иероглиф/формулу пальцем, апп показывает эталон. Mochi умеет для японского — большое преимущество для конкретной аудитории.

#### M7. Pomodoro / focus mode для study session
25 мин таймер + автопауза, brain break экран, статистика серий focus-сессий. Маленькая фича, но интегрирует apple в дневную рутину студента.

#### M8. Цветные теги + цвет рамки карты по тегу
Сейчас deck имеет цвет/картинку — расширить на теги внутри. Визуальный шрифт сильно ускоряет навигацию в колоде 200+ карт.

#### M9. Quick-add bar (горячая клавиша/виджет)
Десктоп: глобальный hotkey → mini popup «front / back / deck» → сохранил. На Android: home screen widget + share-target из любого приложения (выделил текст в браузере → «share to flashcards»). Сокращает time-to-card до 5 секунд.

### Long-term — амбициозные / стратегические направления

#### L1. AI-tutor чат внутри колоды (RAG по картам пользователя)
Чат «спроси что угодно по этой колоде» — LLM с retrieval поверх всех карт пользователя. Memrise MemBot и Quizlet Q-Chat доказали продуктовую тягу (хотя Q-Chat закрылся — поучительно, нужен моат). У нас моат — это privacy (всё локально + Git, ключ юзера).

#### L2. Conversational practice для языковых колод (роле-плей)
LLM играет роль собеседника, использует слова из активной колоды, корректирует грамматику. Войс через Capacitor + Web Speech. Прямой аналог Memrise Role Play Buddy.

#### L3. Knowledge graph visualization (как RemNote)
Граф колод/тегов/карт со связями `[[card]]`. d3.js или Cytoscape визуализация. Сильное эстетическое + аналитическое преимущество для «студенческого» позиционирования.

#### L4. Multi-device real-time collaboration на одну колоду
Через тот же Git-бэкенд: pair-study (два студента готовятся вместе), teacher → students push deck. CRDT для одновременного редактирования. Сложная инженерная задача, но открывает B2B (классы, репетиторы).

#### L5. Shared decks marketplace (опционально)
Каталог публичных колод (через GitHub Topics или отдельный реестр). Скачать → fork в свою папку. Естественно ложится на текущую Git-архитектуру: каждая колода = репозиторий. Это путь Anki, но дешевле и без серверов.

#### L6. Exam-date scheduling (как RemNote)
«У меня экзамен 15 июня, intensity = intense» → FSRS уплотняет график так, чтобы все карты прошли N циклов до даты. Аналитика «успеваешь / отстаёшь».

#### L7. Web app + browser extension (через ту же кодовую базу)
Сейчас Capacitor → Android. Тот же Next.js легко даёт web build + Chrome extension (выделил слово → mini-popup «добавить в колоду X»). Cross-platform за минимум усилий — Tinycards именно этого не сделал в своё время.

## 4. Рекомендуемый MVP-roadmap (6 месяцев)

### Sprint 1-2 (приоритет 1)
- C2 (cloze deletion) — простая в реализации, огромный uplift
- C4 (markdown) — react-markdown + KaTeX, ~2 дня
- C5 (streaks + heatmap) — чисто UI/state, retention бустер

### Sprint 3-4
- C1 (FSRS-6) — есть TS-библиотека `fsrs.js` / `ts-fsrs`, ставится через npm
- C6 (type the answer) — режим в study UI
- C7 (Git conflict resolution) — backend-критично, без этого скейл невозможен

### Sprint 5-6
- C3 (image occlusion) — конкурентный паритет с Anki/Mochi
- H1 (AI генерация) — Anthropic Claude или OpenAI ключ пользователя
- H7 (statistics dashboard) — данные уже есть, нужен Recharts

### Sprint 7-8
- H11 (Anki import) — открывает миграцию с конкурента №1
- H2 (несколько режимов) — match/MCQ дешёвы в реализации
- H4 (bookmark) + H5 (smart decks)

## 5. Стратегические выводы

### Моя уникальность — это privacy + Git
**Не надо** конкурировать с Quizlet/Memrise за массовый рынок и AI-фичи в облаке. **Надо** позиционироваться как «Obsidian для флешкарт» — для людей, которым важна локальность данных, version control, owns your data.

### Что копировать без зазрения
**FSRS, image occlusion, cloze deletion, markdown, streaks** — это уже не «фичи», а baseline 2026. Без них продукт выглядит сделанным в 2015.

### Где можно обогнать
- **Git-native shared decks** — каждая колода это repo, fork/PR/diff. Никто так не делал.
- **Privacy-first AI** — LLM-ключ пользователя, локальный prompt; никаких карт на чужие сервера.
- **Cross-device sync без серверов** — GitHub/GitLab/Gitea как free бэкенд. Anki требует AnkiWeb. Я не требую ничего.

### Чего избегать (урок Tinycards)
- Не пытаться быть Quizlet-killer для школьников.
- Не вкладываться в gamification «just because» — без community и social loop это пустая работа.
- Не уходить в чистый markdown-only (Mochi уже там) — нужен баланс power-user / casual.

### Главный нарратив для marketing
**«Your flashcards. Your device. Your Git.»**
Это не feature list — это позиция в head пользователя. Все 28 идей выше должны проходить тест: усиливает ли это нарратив или размывает? FSRS усиливает (мощнее = больше power-users). Knowledge graph усиливает (Obsidian-аналогия). Brain Beats / песенки — размывает.
