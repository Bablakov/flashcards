# Задача на следующую сессию: обложки групп и дизайн приложения

> Составлено 2026-08-18 по итогам первой установки на телефон и ПК.
> Читать вместе со спецификацией [`2026-08-18-scope-reset.md`](./2026-08-18-scope-reset.md).

## Откуда взялась задача

Синхронизация заработала на обоих устройствах, приложение используется вживую —
и сразу видно, что интерфейс делался «по функциям», а не по внешнему виду.
Пользователь сформулировал два пожелания:

1. **У групп нельзя поставить картинку** — на плитке выводится только текст.
   Нужна возможность задать изображение; если его нет — показывать название,
   как сейчас.
2. **Проработать дизайн целиком** — и на ПК, и на телефоне.

## Что уже есть в коде (чтобы не делать заново)

- В модели у группы **уже есть поле `cover`** (`lib/model.ts`, `GroupSchema`) —
  имя файла в `media/` по хешу содержимого.
- `components/DeckEditorModal.tsx` умеет выбирать картинку (кнопки «Камера»
  и «Файл»), сохранять её через `saveMedia` и показывать превью.
- `components/DeckCard.tsx` умеет рисовать обложку фоном: если `deck.image`
  задан, грузит его через `loadMediaDataUrl`.

То есть механика есть, но она **не доведена**: изображение не всегда доходит до
плитки, а на подгруппах путь вообще не проверялся. Первым делом стоит проверить
цепочку «выбрал файл → сохранилось в media → показалось на плитке» для группы
верхнего уровня и для подгруппы, и уже потом менять внешний вид.

## Что сделать по обложкам

1. **Проверить и починить цепочку сохранения** для группы и подгруппы, включая
   случай «создаю группу и сразу прикрепляю картинку» (там работает отложенное
   сохранение через `persistPendingDeckImage`).
2. **Правило отображения**: есть обложка → она фоном, поверх полупрозрачная
   подложка с названием; нет обложки → текущая цветная плитка с буквой.
   Название должно оставаться читаемым на любой картинке (затемнение снизу).
3. **Обрезка и вес**: перед сохранением уменьшать до ~1024 px по длинной стороне
   и пережимать в webp. Сейчас файл кладётся как есть, а он уезжает в git —
   несколько фотографий с телефона раздуют репозиторий.
4. **Удаление обложки** — кнопка есть, проверить, что после неё плитка
   возвращается к буквенному виду и файл попадает под сборку мусора (`gcMedia`).

## Что сделать по дизайну

Разбор текущего состояния — что чинить в первую очередь:

| Экран | Что не так сейчас |
|---|---|
| Главная | Плитки групп разной высоты, статистика сверху занимает много места, поиск и статистика конкурируют за внимание |
| Группа | Хлебные крошки мелкие; подгруппы и карточки выглядят одинаково, хотя это разные сущности; на узком экране заголовок с языками переносится |
| Карточка (редактор) | Две стороны идут подряд одинаковыми блоками — непонятно, где заканчивается лицевая; блок «Прогресс запоминания» занимает столько же места, сколько содержимое |
| Самопроверка | Экран настройки перегружен: область, режим, фильтры, количество, порядок и сторона — всё сразу, без приоритета |
| Отчёт | Столбики без подписей значений по оси, разрез по группам не сортируется |
| Нижняя панель | Уже починена (4 пункта + «Ещё»), но иконки и подписи стоит привести к одному стилю с остальными экранами |

Ориентиры, которые стоит зафиксировать до правок:

- **Мобильный экран — основной**, ПК получает ту же раскладку по центру
  (сейчас так и есть), но на широком экране пустые поля по бокам стоит занять:
  либо две колонки списков, либо боковое дерево групп.
- **Одна акцентная цветная вещь на экран.** Сейчас цветом кричат и плитки,
  и уровни, и кнопки — глазу не за что зацепиться.
- **Плотность**: на телефоне в экран должно помещаться 4–5 карточек списка,
  сейчас 2–3 из-за больших отступов.
- **Тёмная тема — основная**, светлая должна быть проверена отдельно: сейчас
  часть контрастов подобрана только под тёмную.

## Порядок работы, который предлагаю

1. Обложки групп (пункты 1–4 выше) — это функциональность, она нужна сразу.
2. Инвентаризация экранов: пройти по шести экранам и выписать конкретные правки.
3. Единая типографика и отступы (шкала 4/8/12/16/24), затем плитки и списки.
4. Проверка светлой темы и широкого экрана.
5. Прогон на телефоне: плотность, попадание по кнопкам, читаемость на солнце.

## Чего делать не нужно

- Менять модель данных: обложка уже описана в формате, ничего мигрировать не надо.
- Трогать логику FSRS, синхронизации и обновлений — они настроены и работают.
- Возвращать голосовые функции.
