# Самопроверка: у длинного ответа срезался верх

> Сессия 2026-09-04, выпуск **1.1.2**. Одна поломка, найденная на телефоне
> после импорта статей Дениса Борисова — карточек, где ответ занимает
> несколько экранов.

## Что было

На перевёрнутой карточке текст прокручивался вниз до самого конца, но его
**начало было недоступно**: первые строки уезжали выше видимой области, и
домотать до них было нельзя.

## Почему

Сторона карточки центрировала текст средствами флекса — тот же блок был и
контейнером прокрутки:

```jsx
<div className="flex min-h-0 flex-1 items-center justify-center overflow-y-auto">
  <div className="... text-center text-3xl">{text}</div>
</div>
```

Пока текст короче контейнера, `items-center` работает как надо. Когда текст
выше — центрирование раздаёт переполнение **в обе стороны**, и верхняя половина
уходит за начало области прокрутки. Прокрутка туда не достаёт: `scrollTop`
не бывает отрицательным. Отсюда ровно тот симптом, который и был описан: вниз
мотается всё, вверх — ничего.

Измерено в браузере на карточке с текстом на 576 символов (`app/study/page.tsx`,
высота карточки 58vh):

| | верх текста относительно начала прокрутки | сколько можно прокрутить |
|---|---|---|
| было | −49 px (за границей) | 49 px из 99 |
| стало | 0 px | 99 px из 99 |

## Что сделано

**1. Прокрутка вместо центрирования.** Контейнер прокрутки стал обычным блоком,
а центрирует обёртка с `min-h-full`:

```jsx
<div className="min-h-0 flex-1 overflow-y-auto overscroll-contain">
  <div className="flex min-h-full flex-col justify-center">
    <div className="...">{text}</div>
  </div>
</div>
```

Короткий текст стоит по центру ровно как раньше (проверено: 226 px сверху и
226 px снизу, полосы прокрутки нет), длинный начинается с первой строки.

**2. Кегль по длине текста** (`textScale`). Раньше любой текст выводился 30-м
кеглем по центру: короткий вопрос — правильно, статья — бесконечная прокрутка
из двух слов в строке. Теперь до 90 символов остаётся крупный кегль по центру,
дальше он уменьшается ступенями, а с 600 символов текст выключается влево.

**3. Вертикальный жест больше не переворачивает карточку.** Переворот по свайпу
считался по общей длине жеста, поэтому пролистывание длинного ответа пальцем
могло засчитаться как свайп. Теперь переворот — только тап или **горизонтальный**
свайп (`|dx| > 40 и |dx| > |dy|`); ещё добавлен `onPointerCancel`, потому что
при перехвате жеста прокруткой браузер не присылает `pointerup`.

## Проверено

- `npx tsc --noEmit`, `npm run test:model` (53 проверки), `npm run build`.
- Живьём в браузере на демо-карточке с длинным ответом: текст начинается с
  первой строки, домотать можно до последней; короткий текст по-прежнему
  по центру.
- Жесты проверены событиями `pointerdown`/`pointerup`: тап — переворот,
  горизонтальный свайп — переворот, вертикальный и «почти вертикальный по
  диагонали» — не переворачивают.

## Что ещё
