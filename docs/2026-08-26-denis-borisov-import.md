# Импорт заметок Дениса Борисова в flashcards-data

> Сессия 2026-08-26. Не про код приложения — про перенос контента из Obsidian
> в данные, которые приложение читает через `flashcards-data`.

## Что сделано

Из вольта `MyObsidianVault2025` (`YearlyMaterial/2025/Personality development/
Denis Borisov`) в `flashcards-data` добавлена группа **«Денис Борисов»** с
двумя подгруппами:

- **«Когнитивные искажения»** — 42 карточки (по одной на каждое искажение 1–42).
  Лицевая сторона — только картинка (без текста), оборотная — название и
  описание. Так в самой заметке-методичке автора и предлагалось изучать: сперва
  текст, потом узнавание по одной картинке.
- **«Основание»** — 24 карточки: вступление, «Искод», шесть текстов из
  «Догмат — Зачем», шесть «Заветов» и десять «Основ». Все три раздела
  (Догмат / Основы / Заветы) собраны в одну плоскую подгруппу, а не в
  трёхуровневое дерево — так просили. Лицевая сторона — заголовок и картинка,
  оборотная — полный текст.

Итого 3 новые группы, 66 карточек, 65 картинок (не нашлось только у вводной
карточки «Основание — вступление» — в исходной заметке картинки не было).

**Добавление тем же вечером**: третья подгруппа — **«Основные идеи»**, в неё
ушла единственная оставшаяся статья из папки автора — «Охота за тишиной. Шум
для больных дебилов» (вред смартфонов и как от них отвыкать), которую в первый
заход не взяли, потому что она не относится ни к «Основанию», ни к
«Когнитивным искажениям». В этой заметке, в отличие от остальных 65, ещё были
ссылки на другие заметки вольта (`[[Название]]`) и разделители `---` посреди
текста — под это дочистил скрипт (см. ниже) и заодно убрал секцию
«Источник» с голой ссылкой на YouTube в конце.

## Как чистился текст

Из тела каждой заметки убраны: строки `Tag:`/`Tags:`, разделитель `---`,
синтаксис вставки картинки `![[...]]` (сама картинка ушла в поле `image`),
голые ссылки (YouTube, telegra.ph), решётки заголовков, `**жирный**` и
`_курсив_`, маркеры цитат `>`. Сам текст — включая опечатки автора — не
трогался. Картинки пережаты так же, как это делает само приложение при
загрузке с телефона: до 1024 px по длинной стороне, WebP, качество 82
(`lib/media.ts:compressImage`) — 26,8 МБ картинок из вольта превратились в
1,4 МБ в репозитории.

Два файла-заглушки без текста (`Основание - Догмат - Зачем.md`,
`Основание - Основы - Как мыслить.md` — просто MOC-заметки с одними тегами)
и файл «Охота за тишиной…» (лежит рядом, но не входит ни в «Основание», ни
в «Когнитивные искажения») в карточки не попали. В названиях два места
поправлены на написание, которым сам автор пользуется в тексте заметок:
«Треиндинство» → «Триединство», «10 БЛАГРОДНЫХ ОСНОВ» → «10 БЛАГОРОДНЫХ ОСНОВ».

## Как это сделано технически

Приложение хранит данные не в файлах на диске, а в IndexedDB браузера
(`LightningFS`), поэтому карточки нельзя было просто дописать в открытый
редактор. Вместо этого: чистый клон `Bablakov/flashcards-data` во временную
папку → генерация `groups/*.json`, `cards/*.json`, `media/*.webp` в точности
по схемам `lib/model.ts` (тот же ID-алфавит, тот же способ хеширования картинок
— первые 20 байт SHA-256) → проверка **этими же Zod-схемами** приложения
(`GroupSchema`/`CardContentSchema`, 0 ошибок) → коммит и `git push` в `main`.

## Что дальше

- Откройте приложение и запустите синхронизацию (или дождитесь автосинхронизации
  при старте) — новая группа появится после `git pull`.
- Если названия карточек-«Основ» или порядок чтения захочется поменять —
  порядок карточек внутри группы приложение никак не хранит и не сортирует
  (в `CardContentSchema` нет поля `order`), так что это можно смело переставлять
  через редактор без последствий для данных.
