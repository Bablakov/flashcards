# Как подключить синхронизацию — пошагово

Приложение хранит карточки в **вашем собственном** GitHub-репозитории: ПК и телефон —
это две копии одного репозитория. Сервера у приложения нет, аккаунт заводить не нужно,
данные никуда, кроме вашего репозитория, не уходят.

---

## Шаг 1. Создать репозиторий для данных (один раз)

1. GitHub → **New repository**.
2. Имя, например `flashcards-data`.
3. **Private** — обязательно, там будут ваши карточки.
4. Без README (пустой репозиторий проще).

> Репозиторий с кодом приложения (`flashcards`) — отдельный и публичный, из него
> скачиваются обновления. Личные данные в нём не хранятся.

## Шаг 2. Создать токен (один раз)

1. GitHub → аватар справа вверху → **Settings**.
2. Левое меню в самый низ → **Developer settings**.
3. **Personal access tokens → Fine-grained tokens** (именно fine-grained: он даёт
   доступ только к одному репозиторию, а не ко всему аккаунту).
4. **Generate new token** и заполнить:
   - **Token name** — любое, например `flashcards-app`;
   - **Expiration** — максимально возможный срок. Запишите дату: когда токен
     истечёт, синхронизация начнёт отвечать ошибкой 401;
   - **Resource owner** — ваш аккаунт.
5. **Repository access → Only select repositories** → выбрать репозиторий с данными.
6. **Permissions → Repository permissions → Contents → Read and write**.
   Строка **Metadata** сама станет Read-only — так и должно быть.
   Больше ничего включать не нужно.
7. **Generate token** → скопировать строку `github_pat_…` целиком.
   Она показывается **один раз**.

## Шаг 3. Заполнить настройки в приложении

Настройки (шестерёнка) → блок **Git синхронизация**. Поля одинаковые на всех устройствах.

| Поле | Что вводить | Где взять |
|---|---|---|
| **URL** | `https://github.com/ЛОГИН/flashcards-data.git` | страница репозитория → зелёная кнопка **Code** → вкладка **HTTPS** → скопировать. Адрес должен заканчиваться на `.git` |
| **Ветка** | обычно `main` | на странице репозитория слева вверху — название текущей ветки |
| **Имя пользователя** | ваш логин GitHub | этим именем подписываются коммиты, оно же идёт как логин при обращении к GitHub (пароль — токен) |
| **E-mail** | почта, привязанная к GitHub | Settings → **Emails**. Если не хотите светить адрес — включите там же «Keep my email addresses private» и возьмите адрес вида `12345678+ЛОГИН@users.noreply.github.com` |
| **Personal Access Token** | строка `github_pat_…` из шага 2 | хранится только на устройстве, в репозиторий не попадает |
| **CORS-прокси** | **оставить пустым** | нужен только браузерной версии; в ПК-приложении, APK и на iPhone запросы идут мимо CORS |

Дальше: **Сохранить настройки** → **Клонировать** (нажимается один раз при
подключении устройства).

## Шаг 4. Второе устройство

Установить приложение (на iPhone — см. [Установка на iPhone](#установка-на-iphone)),
ввести **те же** шесть значений, нажать **Клонировать** — карточки, прогресс
и настройки подтянутся.

Порядок при самом первом запуске: сначала полностью настройте одно устройство и
дождитесь, чтобы счётчик «Не синхронизировано» обнулился, и только потом
подключайте второе.

## Шаг 5. Расписание

В настройках задайте:

- **Напоминания** — дни недели и время (например пн–пт в 08:00). Уведомления локальные,
  интернет для них не нужен.
- **Когда синхронизировать** — при запуске, после изменений, при выходе и/или по расписанию.

Обе настройки хранятся в репозитории и сами появятся на втором устройстве.

## Шаг 6. Как это работает дальше

- Любое изменение (создали карточку, поправили текст, перенесли группу) **сразу становится
  коммитом**. Ответы в сессии складываются в один коммит в конце.
- Без интернета всё продолжает работать: коммиты копятся локально и уедут при первой сети.
  В шапке видно, сколько изменений ждёт отправки.
- Прохождение записывается в отдельный файл журнала **для каждого устройства**, поэтому
  ПК и телефон не мешают друг другу, даже если оба были офлайн.

## Шаг 7. Если что-то сломалось

- **Данные на месте, но приложение странно себя ведёт** → Настройки → «Удалить локальные
  данные» → «Клонировать». Локальная копия соберётся заново из репозитория.
- **Нужен запасной бэкап** → экспорт `.fcdeck` из группы (текст + картинки одним файлом).
- **Хочу посмотреть историю** → откройте репозиторий на github.com: карточки лежат
  обычными JSON-файлами, у каждой правки видна дата и описание.
- **Приложение просит обновиться и работает только на чтение** → на другом устройстве
  версия новее, обновите эту. Так сделано специально, чтобы старая версия не испортила
  данные нового формата.

## Установка на iPhone

Apple не даёт ставить приложения мимо App Store без подписи. Платного аккаунта
разработчика ($99 в год) у проекта нет, поэтому `.ipa` в релизе **не подписан** —
его подписывает вашим бесплатным Apple ID программа-установщик на компьютере.

### Первый раз

1. На ПК должны стоять **iTunes** и **iCloud для Windows** — обязательно
   версии с сайта Apple, а не из Microsoft Store (ссылки на нужные версии есть
   на странице загрузки Sideloadly), — и сам **[Sideloadly](https://sideloadly.io)**.
2. Со страницы [Releases](https://github.com/Bablakov/flashcards/releases)
   скачать файл `flashcards-X.Y.Z-N.ipa`.
3. Подключить iPhone кабелем, на телефоне ответить «Доверять этому компьютеру».
4. В Sideloadly перетащить `.ipa` в окно, в поле **Apple account** ввести
   Apple ID, нажать **Start** и ввести пароль (и код, если включена
   двухфакторная защита). Можно завести для этого отдельный Apple ID.
5. На iPhone: **Настройки → Основные → VPN и управление устройством** →
   строка с вашим Apple ID → **Доверять**.
6. На iOS 16 и новее: **Настройки → Конфиденциальность и безопасность →
   Режим разработчика** → включить, телефон перезагрузится. Пункт появляется
   только после первой установки такого приложения.
7. Открыть Flashcards и подключить синхронизацию — шаги 3–4 выше.

### Что важно знать

- **Подпись бесплатного Apple ID действует 7 дней.** Потом приложение перестаёт
  открываться — данные при этом не пропадают. Достаточно ещё раз поставить тот же
  `.ipa` через Sideloadly тем же Apple ID. В Sideloadly есть автопродление
  (включается в дополнительных параметрах при установке, а в iTunes на
  странице iPhone — «Синхронизировать с этим iPhone по Wi‑Fi»): пока ПК
  включён и телефон в той же сети, подпись продлевается сама.
- **Всегда один и тот же Apple ID.** С другим iOS не даст поставить поверх, и
  приложение придётся удалить вместе с локальной копией. Карточки при этом
  останутся в репозитории — после «Клонировать» вернутся, но то, что не успело
  синхронизироваться, пропадёт.
- **Бесплатным Apple ID можно подписать не больше трёх приложений** одновременно.
- **Обновление.** Раз в сутки приложение проверяет релизы и, когда в новом есть
  `.ipa`, показывает «Доступна версия N» с кнопкой «Открыть релиз». Новый `.ipa`
  ставится через Sideloadly поверх старого — данные и настройки сохраняются.
- **Напоминания.** При первом включении iOS спросит разрешение на уведомления;
  если отказать, включить их потом можно в настройках iPhone → Flashcards.
